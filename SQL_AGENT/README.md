SQL Agent using LangChain SQLToolkit

This project implements an intelligent SQL Agent using LangChain’s SQLToolkit that enables querying an internal SQL database through natural language. The agent converts user questions into SQL queries, executes them on a local database, and returns accurate results without requiring manual SQL writing.

Key Features:

Natural language to SQL conversion

Query execution on an internal database

Built using LangChain SQLToolkit

Simple, modular Python implementation

Tech Stack: Python, LangChain, SQLToolkit, SQLite, LLM

Usage:

python sql_agent.py


This project demonstrates practical application of LLM-powered agents for structured data access.
